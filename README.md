# ADVANCE-COMPUTER-VISION
Pada penelitian ini digunakan dataset Adult Income yang diperoleh dari UCI Machine Learning Repository. Dataset ini berisi data demografi dan pekerjaan individu yang digunakan untuk memprediksi apakah pendapatan seseorang lebih besar dari 50K per tahun atau tidak.

Analisis ini dilakukan untuk mengetahui performa metode Random Forest dalam melakukan klasifikasi pendapatan individu berdasarkan variabel yang tersedia pada dataset.

Dataset yang digunakan adalah Adult Income Dataset yang diperoleh dari Kaggle . 
Dataset ini memiliki:
•	Jumlah data: ±48.842 baris 
•	Jumlah variabel: 14 variabel fitur dan 1 variabel target 
Variabel target pada dataset ini adalah:
•	income 
Target digunakan untuk memprediksi:
•	Pendapatan ≤50K 
•	Pendapatan >50K

Metode penelitian yang digunakan meliputi:
1.	Pengumpulan dataset 
2.	Preprocessing data 
3.	Penanganan missing value 
4.	Transformasi data 
5.	Pembangunan model Random Forest 
6.	Evaluasi model 
7.	Interpretasi hasil

DATASET : https://www.kaggle.com/datasets/omkargurav/face-mask-dataset
